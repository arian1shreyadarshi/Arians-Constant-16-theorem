# Arian's Constant 16 Theorem
Discoverer: Arian Shreyadarshi (@mearian) - 2026

Pattern: {(2n+7)²-(2n+5)²} - {(2n+3)²-(2n+1)²} = 16

For any 4 consecutive odd numbers, result is always 16.

Proof:
(2n+7)²-(2n+5)² = 8n+24
(2n+3)²-(2n+1)² = 8n+8
Difference = 16

General formula: 4d²
When d=2, we get 16.
